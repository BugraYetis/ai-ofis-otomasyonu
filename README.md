## 📌 Proje Hakkında

> 🚧 **Yapım aşamasında.** Gelişmeleri portfolyomda paylaşıyorum.

Ofisteki tüm bilgisayarları tek bir ağda birbirine bağlayan ve birbirleriyle haberleşmelerini sağlayan yapay zeka otomasyon sistemi. Yapay zeka verilen işleri otomatik olarak yapıp sonuçları geri gönderiyor; tüm sistem bir mobil uygulamadan yönetiliyor ve kontrol ediliyor. Sistem şu an geliştirme aşamasında.
